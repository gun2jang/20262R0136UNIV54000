# Dino Runner

공룡이 점프하거나 숙여서 장애물을 피하고, 특정 점수에서는 익룡으로 변신해 비행하는 순수 HTML/CSS/JavaScript 게임입니다. 외부 라이브러리나 이미지 없이 Canvas로 직접 그립니다.

## 주요 기능

- 1~3개 묶음으로 무작위 등장하는 선인장과 시작 8초 이후 등장하는 새
- 300~399점, 600~699점, 900~999점… 구간마다 익룡으로 변신하고, 구간이 끝나면 공룡으로 복귀
- 익룡 구간에서는 서로 다른 높이로 날아오는 새를 위아래로 피합니다.
- 약 1.35초 동안 지면이 내려가고 날개가 펼쳐지며 이륙합니다. 공룡으로 돌아올 때는 지면이 올라오고 부드럽게 착지합니다. 기존 장애물은 배경과 함께 사라지며, 변신을 마치면 조작이 이어지고 1.5초 뒤부터 새 장애물이 등장합니다.
- 시간이 지날수록 빨라지는 장애물 이동과 점수 증가
- 숙인 자세를 반영한 충돌 판정과 게임 오버 후 재시작
- 현재 점수와 최고점수 표시. 최고점수는 재시작해도 유지되며 같은 브라우저에 저장됩니다. 로컬 파일 저장이 차단된 환경에서는 게임을 연 동안만 유지됩니다.

## 실행

네 파일을 같은 폴더에 두고 `index.html`을 더블클릭해 브라우저에서 여세요. 설치, 서버, 인터넷 연결이 필요하지 않습니다.

파일을 수정한 뒤에는 페이지를 새로고침하세요. Codex 안에서 키가 반응하지 않으면 먼저 게임이 열린 브라우저 패널을 선택하세요.

## 조작

- Space, ↑ 또는 게임 화면 클릭으로 시작하고 점프합니다. 공중에서는 다시 점프할 수 없습니다.
- ↓ 키를 누르고 있으면 지상에서 숙입니다. 새는 숙여 피하고 선인장은 뛰어넘으세요. 숙이는 동안에는 점프할 수 없습니다.
- 익룡으로 변신하면 ↑ / ↓ 키를 누르고 있는 동안 위 / 아래로 이동합니다. 두 키를 떼거나 동시에 누르면 높이를 유지합니다.
- 시작/재시작 버튼으로도 시작할 수 있습니다.
- 선인장이나 새에 부딪히면 게임이 멈춥니다. 0.4초 뒤 같은 조작이나 재시작 버튼으로 다시 시작하세요.

게임 화면은 로드·시작 시 키보드 포커스를 받으며, 키 코드가 없는 입력도 실제 키 값으로 인식하도록 처리했습니다.
