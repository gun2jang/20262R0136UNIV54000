# Dino Runner

공룡이 점프하며 선인장을 피하는 순수 HTML/CSS/JavaScript 게임입니다. 시간이 지날수록 조금씩 빨라집니다.

## 실행

네 파일을 같은 폴더에 두고 `index.html`을 더블클릭해 브라우저에서 여세요. 설치, 서버, 인터넷 연결이 필요하지 않습니다.

## 조작

- Space, ↑ 또는 게임 화면 클릭으로 시작하고 점프합니다. 공중에서는 다시 점프할 수 없습니다.
- 시작/재시작 버튼으로도 시작할 수 있습니다.
- 선인장에 부딪히면 게임이 멈춥니다. 0.4초 뒤 같은 조작이나 재시작 버튼으로 다시 시작하세요.
